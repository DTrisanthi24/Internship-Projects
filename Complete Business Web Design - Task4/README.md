📌 Project Overview
The **Deccan Dhaba Website** is a fully responsive, multi‑page static website designed to showcase a restaurant’s brand, menu, and contact information. It demonstrates front‑end development skills in **HTML5, CSS3, and JavaScript**, with optimized images and a validated contact form.

---

🎯 Objectives
- Build a **responsive website** accessible across desktops, tablets, and mobile devices.  
- Provide clear navigation between **Home, About, and Contact pages**.  
- Optimize images for faster load times.  
- Implement a **contact form with validation** for user engagement.  
- Deploy the project on **GitHub Pages / Netlify** for free hosting.  

---

✨ Features
- **Multi‑page structure**:
  - `index.html` → Home page with images and welcome message.  
  - `about.html` → About section describing Deccan Dhaba’s story and specialties.  
  - `contact.html` → Contact form with JavaScript validation.  

- **Responsive Design**:
  - Navigation adapts to smaller screens using CSS media queries.  
  - Images scale automatically (`max-width: 100%; height: auto;`).  

- **Image Optimization**:
  - Lazy loading (`loading="lazy"`) for faster performance.  
  - Compressed `.jpg` and `.avif` formats for reduced file size.  

- **Contact Form Validation**:
  - Ensures all fields (Name, Email, Message) are filled before submission.  
  - Alerts users if any field is missing.  

- **Deployment Ready**:
  - Compatible with **GitHub Pages** and **Netlify**.
